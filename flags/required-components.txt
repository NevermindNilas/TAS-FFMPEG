# ===========================================================================
# flags/required-components.txt
#
# THE CONTRACT. Every line is a component one of the two consumers actually
# reaches, with file:line evidence in the trailing comment. After every build
# scripts/verify-output.sh interrogates the BUILT ffmpeg binary
# (`ffmpeg -encoders`, `-decoders`, `-muxers`, `-demuxers`, `-filters`,
# `-protocols`, `-bsfs`, `-devices`) and fails the build if any of these is
# absent on the platform it applies to.
#
# This is the difference between "we think the flags are right" and "the build
# proves it". flags/*.flags say what we ASKED configure for;
# --disable-autodetect, a missing header, a silently-failing dep or a renamed
# component can all make configure quietly give us less. Only the binary knows.
#
# ---------------------------------------------------------------------------
# FORMAT
#     <kind>  <name>  <platforms>      # <provenance> -- <evidence>
#
#   kind      encoder | decoder | muxer | demuxer | filter | protocol
#             | bsf | device
#   name      THE CLI NAME, as `ffmpeg -encoders` prints it -- NOT the
#             configure name. They differ, and that is the entire point:
#             configure calls it `movtext`, `ffmpeg` calls it `mov_text`;
#             configure `libaom_av1`, ffmpeg `libaom-av1`; configure
#             `image_png_pipe`, ffmpeg `png_pipe`. flags/*.flags use the
#             configure spelling and scripts/validate-flags.sh checks THOSE;
#             this file uses the spelling a user types and verify-output.sh
#             checks THESE. Both are needed.
#   platforms `all`, or a comma-separated list of `<os>` / `<os>/<arch>`
#             tokens, optionally prefixed with `!` to subtract. Evaluated
#             left to right. Known platforms:
#                 windows/x86_64
#                 linux/x86_64  linux/arm64
#                 macos/x86_64  macos/arm64
#             e.g. `all,!macos`            everything except macOS
#                  `windows,linux/x86_64`  Windows plus Linux x86_64 only
#
# Demuxer names are matched against each comma-separated component of what
# ffmpeg prints, because ffmpeg lists one demuxer as
# `mov,mp4,m4a,3gp,3g2,mj2`. So `demuxer mov` and `demuxer mp4` both match it.
#
# ADDING A LINE: only with evidence. A component nobody reaches does not
# belong here -- it would make the build fragile for no gain, and the union
# rule already keeps every default-on component in the binary anyway.
# ===========================================================================
